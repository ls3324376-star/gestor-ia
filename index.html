Assistente de IA — análise orientada

O sistema prepara um pedido completo para um modelo de IA, utilizando os indicadores da empresa fictícia. Copie e cole no ChatGPT para receber uma análise. Esta versão não envia dados automaticamente e não possui integração via API.

A IA pode errar. Confirme todos os números com os cálculos do sistema. Não insira dados reais de clientes, senhas ou informações pessoais.

Conclusão preliminar da pesquisa

Gere um resumo com os indicadores experimentais registrados. Não substitua a conclusão científica por respostas geradas automaticamente.
